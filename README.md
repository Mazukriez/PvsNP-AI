# PvsNP-AI
PvsNP-AI is an open-source AI-assisted mathematical research laboratory designed to explore computational complexity through hypothesis generation, automated experimentation, adversarial counterexample search, literature analysis, and machine-checked formal verification.
I created the PvsNP-AI starter repository with the first executable MVP structure.
Included
- Python package and CLI
- Explorer / Skeptic / Director agent interfaces
- SAT instance generator
- PySAT solver integration
- Reproducible experiment runner
- Automatic counterexample capture
- SQLite research database
- Hypothesis lifecycle/status model
- Initial Lean verification boundary
- pytest tests
- GitHub Actions CI
- Dockerfile
- .env.example
- Architecture documentation
- Research methodology foundation
The Python source also passed a syntax/compile check.
